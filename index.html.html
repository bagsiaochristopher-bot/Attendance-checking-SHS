ID QR Attendance System

1. Gumawa ng QR Code ng Estudyante

I-type ang Student ID o Pangalan ng estudyante para gawan ng QR Code para sa kanilang ID card.

Tip: Pwede mong i-right click ang QR code para i-save o i-copy ang imahe at ilagay sa template ng ID nila.

2. Attendance Scanner (Para kay Teacher)

I-harap ang QR code ng ID ng estudyante sa camera para ma-check ang attendance.
